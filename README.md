# SOLID en TypeScript

Este repositorio local contiene ejemplos corregidos de los principios SOLID:

- SRP: Principio de Responsabilidad Única
- OCP: Principio Abierto/Cerrado
- LSP: Principio de Sustitución de Liskov
- ISP: Principio de Segregación de Interfaces
- DIP: Principio de Inversión de Dependencias

> Nota: este proyecto es local y no se sube a GitHub.

## Archivos

- `solid-principios.ts`: ejemplos TypeScript de los principios SOLID.

## Uso

Compilar con:

```bash
npx tsc solid-principios.ts --noEmit
```

O ejecutar directamente con `ts-node` si lo deseas.
